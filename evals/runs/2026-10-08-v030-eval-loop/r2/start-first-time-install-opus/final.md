欢迎使用 Intgral！已经用管理员给的地址把 Intgral 连接装好了：

```
claude mcp add --transport http --scope user intgral https://mcp.example.test/mcp
→ Added HTTP MCP server intgral with URL: https://mcp.example.test/mcp to user config
```

装在 user 级别，以后每个 Claude Code 会话都能用。

**下一步：**
- 请**重启 Claude Code**（或重新加载 MCP），Intgral 的工具才会出现。
- 如果需要登录，客户端会自己弹出 Intgral 的登录页，在那里完成就行。不要把 token 或密码发到聊天里。
- 打开 Intgral 的链接要等连上以后才能拿到，重启后我会把链接发给你。
