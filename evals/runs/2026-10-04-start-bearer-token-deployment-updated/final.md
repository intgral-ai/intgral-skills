欢迎开始用 Intgral！地址我收到了：`https://mcp.example.test/mcp`。

因为管理员给的是固定访问令牌，这一步需要你自己在终端里完成。令牌只在你自己的电脑上用，我不会经手，所以请不要把它发到聊天里。

**1. 在你自己的终端运行下面这条命令**（把 `<你的令牌>` 换成管理员给你的令牌，两边的尖括号也去掉）：

```bash
claude mcp add --transport http --scope user intgral https://mcp.example.test/mcp --header "Authorization: Bearer <你的令牌>"
```

- `--scope user` 的意思是装在你的用户级别，以后每个会话都能用，不用每次重装。
- 如果提示已经有一个叫 `intgral` 的连接，先别删，把提示原样发给我，我帮你看是保留还是替换（发的时候注意别带上令牌）。
- 如果令牌已经不小心发到别的聊天或群里了，最好请管理员换一个新的。

**2. 重启 Claude Code**（或者重新加载）。新加的连接一般要重启后，Intgral 的工具才会出现。

**3. 回来跟我说一声“装好了”。** 连上以后我会给你 Intgral 后台的链接（链接要连上后才能拿到，我不会猜地址），并列出这个部署能做的事。一般包括：
1. 查 SKU 的状态和现有信息
2. 用表格或资料导入，建产品草稿
3. 修改产品文案或站点 listing
4. 看图、补图、调整图片

（调研和视频要看你们的部署有没有开通，连上后我再确认。）

如果运行命令时报错，把输出发给我就行，**记得先把里面的令牌删掉**。
