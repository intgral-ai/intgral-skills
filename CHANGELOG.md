- Listing, research, video, start: a SKU the catalog does not have is looked up among listings before anything is called missing (INT-1090). `medusa.get_product` → `not_found` is not the end: the agent reads `GET /admin/amazon/listings?seller_sku=<SKU>&view=all`, works from the listing it finds (`get_listing_context` returns `product: null`; its `listing_erp_url` opens), says the catalog has no product yet and offers the bootstrap import as the user's choice, never in the same turn; in neither place it says so and guesses no near-match. Scenarios `listing-sku-only-in-listings`, `listing-sku-in-neither-place` and `start-sku-only-in-listings` (the same SKU through the entry skill, where the demo failed); run columns not run. Guidance only.
- Listing: A+ images follow the decisions ratified on 2026-10-06 (INT-1095), which the ERP now enforces on `medusa.attach_aplus_images`. Image text replaces "图里不放文字": only the user's exact wording, never the agent's copy, with a BCP-47 `locale` per text image; wording with prices, promotions, shipping, guarantees, competitors or unverified claims is refused, with the reason, before anything is proposed. One confirmation covers module, size, prompt, text, locale and storing. A file the host cannot make conforming is not sent (replaces "store it anyway"): the user gets the target size and the product page's A+ card for their own upload; a refusal's `findings` name the size. The tool takes `product_id` or `sku`; `view_product_images` returns stored A+ images apart in `aplus_images`; deleting stays with a human in the ERP. Scenarios `listing-aplus-user-text` and `listing-aplus-forbidden-text` (new), `-propose-first` v2 and `-confirmed-store` v3 on the new tool contract; baseline and final runs recorded.

- Start: fixed access tokens never pass through the chat (INT-1010). `intgral-start` ships `scripts/set-token.ps1` (Windows, PowerShell 5.1, UTF-8 with BOM) and `scripts/set-token.sh` (macOS): the user pastes the token into a local hidden-input window, the script checks it with the gateway's `initialize` and saves it only on HTTP 200 — as the user environment variable `INTGRAL_MCP_TOKEN` (Windows) or in the login Keychain, exported to apps at each login (macOS) — and prints only its length.
